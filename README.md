Project Title: "Flight & Airport Operations System"

Problem Statement: Lost luggage costs airlines billions every year and leaves passengers frustrated and distrustful. The root cause? Outdated systems rigid conveyor scheduling, slow check-in queues, and poor handling of disruptions like emergency landings or sudden weather reroutes.

Objective: To design and implement a GUI-based Flight & Airport Operations System using Qt (C++ framework) that provides:

->Develop a practical airport operations system that helps manage flights, passengers, baggage, and airport activities efficiently.

-> Implement the core features such as passenger booking, flight search, baggage tracking, emergency landing management, and airport route finding.

-> Apply OOP and Data Structures concepts to solve real-world airport management problems.

->Test and evaluate the system using different inputs and real-life scenarios to check its accuracy, speed, and reliability.

->Demonstrate future scope by creating a system that can be further improved.
